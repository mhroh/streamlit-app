# 🎭 디베이트 클럽 챗봇

Claude API를 활용한 토론 챗봇 Streamlit 애플리케이션입니다.

## 기능

- Claude Sonnet 4.5 모델을 사용한 지능형 토론 파트너
- 실시간 스트리밍 응답
- 논리적이고 균형 잡힌 토론 진행
- 깔끔한 채팅 인터페이스

## 설치 방법

```bash
pip install -r requirements.txt
```

## 실행 방법

```bash
streamlit run test.py
```

## 사용 방법

1. 애플리케이션을 실행합니다
2. Claude API 키를 입력합니다 (https://console.anthropic.com에서 발급)
3. 토론하고 싶은 주제나 의견을 입력합니다
4. Claude와 함께 깊이 있는 토론을 즐기세요!

## 파일 구조

- `test.py` - 메인 디베이트 클럽 챗봇 애플리케이션
- `first.py` - 간단한 환영 페이지
- `requirements.txt` - 필요한 Python 패키지 목록
